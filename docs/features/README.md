# Features

Feature-level specs live here. This directory is intentionally empty for now because the current work is still at product-level planning.

## Why This Directory Exists

The platform will naturally split into large feature areas over time:

- Device preview and control.
- Record and replay.
- Runner and scheduling.
- Performance and event capture.
- Reports and artifacts.
- Mock Driver and regression testing.

When a sub-feature becomes large enough to need its own requirements, design, tasks, acceptance, and traceability, create:

```text
docs/features/<feature>/spec/
```

The overall platform spec stays under:

```text
docs/product/mobile-automation-platform/spec/
```
