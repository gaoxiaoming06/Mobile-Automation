# ADR 0004：通过试运行学习页面内定位与导航资产

- 状态：已接受，分阶段实现
- 日期：2026-07-30

## 背景

旧流程要求用户先录入页面、元素、连接边和页面任务，再生成测试。它把资产建设成本放在首次使用之前，产生大量重复连接和动作资产，也使自然语言测试依赖数据库内部结构。

目标是让新 App 在零资产状态下也能从完整操作描述开始测试，同时确保一次误点或一次偶然成功不会污染后续执行和全局导航。

## 决策

1. ScriptFlow 是测试过程的事实来源，只保存业务步骤、参数、页面前后置条件和结果断言。
2. PageAsset 只描述页面身份；InteractionAsset 只描述某个页面或表面内的非坐标定位经验；NavigationEntry 只描述一次已经验证的安全页面跳转。
3. AI 可以生成结构合法但未验证的 `trial_ready` 草稿。该草稿只能真实试运行或保存为草稿，不能直接作为正式用例执行。
4. 试运行复用正式执行器，但默认关闭视频并禁止无限循环。设备动作通过和业务结果通过分别记录。
5. 没有自动结果判定时必须由用户确认结果。失败、未确认或用户否认的运行不允许启用任何学习资产。
6. 交互候选只来源于实际成功执行的语义步骤。系统先保存不可执行的证据，至少累计 3 次独立成功运行和 2 份证据后才允许晋级；晋级时拒绝坐标、区域、边界和固定点击点。
7. ScriptFlow 永不保存 InteractionAsset ID。预览按 App、平台、所属页面、动作和语义目标严格匹配唯一资产，并冻结完整资产版本到计划摘要；重复匹配直接报错。
8. 试运行步骤只有同时具备已知 `onPage`、已知 `expectPage`、成功语义定位和通过的目标页面断言，才能生成 NavigationEntry 候选。候选通过多次运行门槛和确定性校验后由后台进入导航索引；重复成功只合并证据和提升版本，不重复建条目。
9. FlowVerification 绑定 sourceHash。脚本内容变化后不继承旧验证；只有准确版本已验证的启用用例和已接受 NavigationEntry 可以提供导航索引。
10. 导航学习复用步骤定位结果、执行后截图和页面断言，不为同一步额外截图或重复 OCR。
11. 资产录制降级为高级校准能力，不再是生成测试前的必经入口。
12. 精确文字交互和已验证导航使用确定性规则晋级，不调用 AI。页面身份、图标和其他高歧义候选才进入异步 AI 分析；AI 只能提出候选，不能绕过稳定性、冲突和隐私校验发布资产。
13. 学习证据和正式资产必须按 App ID 与平台隔离。普通执行不持续调用 AI；只有达到分析门槛的新候选才产生一次后台分析请求。
14. 已发布交互资产连续 3 个运行都发生明确定位失败时自动标记为 `degraded` 并停止复用。成功使用会清零连续失败；ANR、网络、业务断言和其他非定位错误不计入资产健康度。
15. ScriptFlow 将组合粒度 `kind`、主要目的 `purpose` 和步骤职责 `role` 分开表达。AI 负责语义分类，确定性校验器负责拒绝导航流程中的业务副作用等矛盾组合。
16. 临时执行历史与用例中心分离。纯导航流程不允许保存到用例中心；历史只保存可重放脚本快照、非敏感参数和 Run 引用，不复制执行附件。
17. 持续学习当前由服务端源码常量 `ASSET_LEARNING_MODE` 控制，生产固定为 `disabled`。不提供数据库设置、HTTP API、前端控件或环境变量覆盖；只有测试生成与执行第一阶段验收通过后，才允许通过独立代码评审依次改为 `shadow` 和 `active`。关闭学习不影响已有 active 资产读取和健康统计。

## 明确禁止

- 不恢复 `ref`、元素 ID、截图区域或固定坐标目标。
- 不把动作执行完成等同于业务结果正确。
- 不自动保存屏幕上的全部文字和控件。
- 不从失败运行、被否认结果或歧义候选中学习。
- 不长期维护旧图执行和 ScriptFlow 两套可编辑事实来源。

## 结果

首次使用成本降低，测试脚本保持业务可读，页面、交互和导航经验由真实成功运行按需积累。普通用户只需描述、执行和查看结果；仅在测试结果本身无法自动验证时确认结果。代价是需要维护学习聚合、版本冻结、资产冲突和健康度治理；自定义纯图形入口仍可能需要高级校准。

页面候选提取、自定义图形纠正、参数化动态列表和跨平台 locator variant 按独立阶段继续实现，不通过降低唯一性阈值来提前放行。
