# Product Specs

Product-level specs describe the overall automation testing platform, not a single sub-feature.

## Current Product

| Product | Scope | Status | Entry |
|---|---|---|---|
| 自动化测试平台 | Android / iOS app automation testing platform | draft | [mobile-automation-platform](mobile-automation-platform/README.md) |

## Product vs Feature

- `docs/product/<product>/spec/` is for the whole platform.
- `docs/features/<feature>/spec/` is for future sub-features such as device discovery, record/replay, reporting, or Mock Driver.
