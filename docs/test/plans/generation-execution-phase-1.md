# 测试生成与执行第一阶段验收

## 目标

验证自然语言生成的 ScriptFlow 能在真实 Android 设备上稳定完成目标查找、页面确认、受控恢复和结果判定。持续学习保持 `disabled`，本验收不依赖候选资产写入或自动发布。

## 通过标准

- 固定 20 次真实设备运行，至少 19 次通过。
- 唯一允许的失败必须被归入公开失败类型，并给出正确下一步。
- 任意一次错误点击后被判定为通过，整个阶段直接判定失败。
- 用户界面不得显示内部页面 ID、步骤 ID、locator payload 或异常堆栈；完整技术信息仅保留在 HTML 报告。
- 每次执行关闭视频录制，失败现场使用步骤截图和 HTML 报告检查。
