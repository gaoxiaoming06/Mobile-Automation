# Apps

Application entry points.

| App | Purpose |
|---|---|
| [dashboard](dashboard/) | React Web dashboard for devices, ScriptFlow authoring, AI generation, stability exploration, and run reports |
| [server](server/) | Node.js REST/WebSocket service for ScriptFlow orchestration, storage, reports, AI, and Agent relay |
| [device-agent](device-agent/) | Local device node that registers Android, iOS, and HarmonyOS devices with the server |
