# Dashboard

React + TypeScript + Vite application for the Mobile Automation workbench.

Responsibilities:

- Device inventory, capability display, pairing-aware selection, and manual control.
- Browser preview through Agent-backed Android scrcpy with screenshot fallback. HarmonyOS preview currently uses screenshot polling; the experimental HarmonyOS stream bridge is not the dashboard default.
- ScriptFlow case center for saved YAML use cases, typed parameters, verification status, and run control.
- AI ScriptFlow generation, manual step editing, preview/plan digest, trial runs, repair, and outcome review.
- Stability exploration for controlled random testing with Android app monitor integration.
- Run result pages with screenshots, logs, metrics, video evidence, and HTML reports.
- Advanced-only asset calibration and PageAsset library maintenance.
