# Packages

Shared libraries and domain modules.

| Package | Purpose |
|---|---|
| [shared](shared/) | Shared schemas, device/action/run contracts, Agent envelopes, and utility helpers |
| [script-flow](script-flow/) | ScriptFlow v1 YAML parser, validator, compiler, and serializer |
| [android-driver](android-driver/) | Android ADB/scrcpy/logcat/metrics/app-monitor driver |
| [ios-driver](ios-driver/) | iOS libimobiledevice/xcrun/WDA driver |
| [harmony-driver](harmony-driver/) | HarmonyOS HDC/uitest/hilog driver |
| [runner-core](runner-core/) | Platform-neutral run state machine and run config normalization |
| [graph-core](graph-core/) | Page identity models and matcher utilities for PageStateService |
| [report-core](report-core/) | HTML report rendering from stored run data |
| [test-support](test-support/) | Mock Driver, fixtures, builders, and assertions |
| [mcp-adapter](mcp-adapter/) | REST-backed MCP adapter for ScriptFlow generation/execution/reporting |
| [cli](cli/) | REST-backed command-line helper for devices, flows, runs, and reports |
