# Shared

Shared TypeScript types and utilities.

Current contents:

- `Platform`, `DeviceInfo`, `DeviceCapabilities`, and default capability helpers for Android, iOS, and HarmonyOS.
- `ActionStep`, `DeviceActionRequest`, semantic action contracts, expectations, conditions, and coordinate conversion helpers.
- ScriptFlow persistence and verification types shared by server, dashboard, CLI, and MCP adapter.
- `RunConfig`, `TestRun`, `StepResult`, artifacts, metrics, events, Android app monitor summaries, and public execution failure shapes.
- Device Agent session, device visibility, lease, command envelope, result envelope, and command-channel message types.
- PageAsset, InteractionAsset, NavigationEntry, learning session/candidate/aggregate, and screen-understanding contracts.
